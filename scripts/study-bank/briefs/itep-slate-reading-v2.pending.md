1. **2026-10-31, itep-reading-v2, packet p2, named by a and b on the same 6 main-idea items (counted): a residual
   main-idea cast.** Even with breadth drawn per item, the six main-idea sets in p2 read as one cast to a and b: the
   key is the only option spanning the whole passage, one distractor is a one-paragraph detail, one names the wrong
   cause or person, one is too broad. Probe 2 had seen the same thing batch-wide before the gate (over-general option
   never keyed 0/6; key names a change/outcome 12/14) and by prereg §3b it went to the gate unrevised. The per-item
   breadth draw controls which option is WIDEST, not whether the key is the only WHOLE-PASSAGE option. Fix for v3:
   draw "number of whole-passage options" (1 / 2 / 4) per item as its own axis, and let some keys be a one-part
   summary of the central paragraph when the passage is a single episode.
2. **Same batch, a and c (D-P3B, all six items dropped): frequency contradiction.** "Each morning she lit a fire"
   vs "Bread was baked on Tuesdays and Fridays" vs "by 1895 the oven was lit only on Fridays". Add to the story-logic
   rule: check every frequency word (each, every, daily, only on) against every schedule in the text.
3. **Same batch, a and c (B-P3A-5): a time-scope stem with an earlier event.** "By the end of the group's first year"
   admits an event from the year's start (the nickname, spring 1961) as a second true answer. A "by time T" stem needs
   distractors that are false at T, not merely earlier.
4. **Same batch, c (B-P3A-4): a purpose stem about a character's question keyed to the writer's purpose.** "Why does
   the reporter ask..." keyed "to show what Derwin valued", while "to suggest he regretted leaving racing" fits the
   reporter's motive. Purpose stems name whose purpose (the writer's) explicitly.
5. **Same batch, p3 a only, no drop: one plot template across history passages** (19th-century town problem,
   innovator, opposition, half-funded trial, unplanned success, the doubter converted; "the sceptic comes round" keys
   on inference/purpose/main-idea). Assign each Part 3 passage an idea shape (and whether the doubter is right) per
   passage, instead of "different shapes within an author".
6. **Same batch, p1 c and p2 a (different packets), no count: vocabulary distractors are always distant dictionary
   senses**, so the key is the only sense that fits any sentence of that kind; c adds the key is the most common
   sense on 4 items. v2 R8 fixed the one-field case and moved the tell. Require one distractor per set that is a
   near-synonym fitting the sentence's grammar but not its meaning.
7. **Same batch, all three p1 graders, no drop: "in order to" stem + options beginning "to"** (H-P1A-1, introduced by
