## Rule 2 — cross-item tells (ask type x key rank)

`alg26-preflight.mjs --merge` bars, on the merged authored file:

- **the best rule "on ask type T, pick rank r"** (one r per T, chosen with
  hindsight to maximise hits) **<= 40% of the batch**, on the six ask types
  AND on a coarse partition that merges count+difference (the grader's own
  "count/width" grouping) and greatest+least;
- the best rule "on mechanism M, pick rank r" <= 40%;
- within every ask type with >= 4 items, no rank holds more than 50%.

The commissioned matrix scores 11/32 = 34.4% (six types), 9/32 = 28.1%
(coarse), 10/32 = 31.3% (mechanism). Every item's rank and ask are checked

the tell grader E found by hand (17/30 in E's categories).

On the KEPT file the same three rules and "pick an end" are REPORTED, not
barred: a hindsight-best rule over a smaller set rises by construction.

Authors also get the direction rule as a writing instruction: the slot rank

error must overshoot on some items and undershoot on others, chosen by the

## Rule 5 — kept from v25

- **Blueprint.** SAT Algebra only: linear equations in one or two variables,
  linear functions, systems of two linear equations in two variables, linear
  inequalities in one or two variables. At most two variables (x, y); **no
  three-unknown systems** (no third equation or "lies on" condition on a
  two-equation system with a constant). One named constant k, except a
  `degenerate-parameter` item may carry a second constant c that the question
  asks for (v22's live hard shape). No k^2 / quadratic step in k, no quadratic
  in x, no absolute value, no divisibility beyond "is an integer". Each grader
  states `on_blueprint` + reason; a grader majority off-blueprint HOLDS the item.
- **Both signs** (mechanism A): the admissible k range straddles the
  zero-slope value and the asked quantity needs both sides; the one-sign
  reading is a named distractor. The analogue for B, C, D is the decision point
  in the table above: the bypass of it must be a named distractor.
- ASCII hyphen-minus only (R3); `≤` `≥` allowed. Four numeric options.
- At most 2 non-integer-constant items, declared, not all offering the
  integer-k answer (R4, v25's).
- Off-by-one next to the key (key +- 1, or a declared endpoint/inclusion
  option adjacent in value): per author A <= 2, B <= 1, C <= 3, D <= 2, batch
  <= 8 (R5).
- No two items share a key value (R9).
- **No repair after freeze.** Nothing re-enters the gate.

## Bars (v25's, unchanged)

- **Blind:** candidate minus matched control <= +10 points; unanimity a
  batch-level rate; control above 90% = NOT MEASURED, not passed.
- **Per-item drop**, any one (three graders): 1 key disputed; 2 not exclusive
  by majority; 3 distractors weak by majority; 4 median >= 2 of 3 distractors
  free-strikable, or the key free-strikable by any grader; 5 a path that does
  not produce its value (confirmed by hand); 6 a majority report plug-back
  reaches the key in <= 2 routine substitutions; 7 a grader majority names the
  item ONE TEMPLATE with an EARLIER item (frozen order above) — same setup and
  same solution steps with different numbers or a cosmetic change; sharing a
  mechanism's insight or the asked quantity alone is not one template.
- **EXT-1:** any item a grader explicitly recommends dropping is dropped.
- **HOLD:** a grader majority off-blueprint.
- **Difficulty:** banked label = three-grader PANEL MEDIAN; the question
  verbatim ("hard" = a decision point routine procedure, including Desmos, does
  not bypass; "medium" = careful multi-step procedure reaches the key). Easy
  is rejected.
- **Kept-set band:** 40-60% at n >= 10; under 10 -> held.
