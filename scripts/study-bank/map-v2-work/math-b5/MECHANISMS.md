# map-v2 Math batch 5 (Number Systems only) — candidate mechanisms for an independent chain check

Step 1 of 2, 2026-10-26. **No slot, brief or prereg exists yet; nothing here is approved.** Batch 4's Number Systems
kept 1 of 11 frozen: graders found six items repeating earlier MAP chains, and authors found four batch-4 slot
mechanisms were exact repeats of v1-v5 items (MB4-N5-01 = v5 rice bags, -03 = v5p Maya $50, -04 = v2 jacket, -08 = v1
farmer). The brief-writer's chain check missed them, so this file is built for someone else to check.

**The earlier list** is `earlier-N-chains.json`: 285 entries, every MAP Number Systems item found in the item files and
DB rows (v1-v5p batch files and their work-folder stage-0 / pre-return versions, batches 1, 2 and 4 with post-return and
first-written versions, and all 47 live DB rows, each matched to a file entry). Each entry carries id, batch, status
(LIVE / staged / withdrawn / dropped by graders / revised away / file only), grade, the item's own `mechanism` field as
the one-line chain, the prompt and the key. It was generated by a read-only script from those files, not from memory;
227 distinct ids. Batch 3 was Geometry only.

**How "closest" was chosen, and why it is not to be trusted on its own.** For each candidate, the three ids under
"closest by my reading" are my judgment after reading the full list; "mechanical top 3" is a tag + token similarity
over the chain and prompt text (it misses chains described in different words, and that is exactly how batch 4's
repeats got through). The checker should search `earlier-N-chains.json` itself; the live ISEE / SSAT keyword hits
noted below are from `mf30-kw.mjs` over `dump-b4`.

**Clusters excluded before drafting** (they cannot meet FORM + K4 with real errors; batch-4 brief): a single quotient as
the answer, rounded-value asks, scientific-notation operations, a single root or power as an end key, .5 x .5 decimal
products, and the signed add/subtract chains already live. Batch 4 also showed decimal ROOTS cannot meet FORM (N8
wrote 1 of 5). Two further blocks found while drafting: **place-value shift items** (x10 / x0.1 siblings) are refused
by HUB, and **GCF / LCM counts** produce multiples that HUB refuses.

**My rating** is how likely the chain is new to MAP: strong / medium / weak / WEAKEST. Of 30: 1 strong, 13 medium,
11 weak, 5 WEAKEST (C04, C20, C27, C29, C30). The simple chain space (signed sums, product-then-adjust, fraction
add/subtract with regrouping, exponent-law evaluation) is saturated; the medium ones sit in narrower places —
repeating decimals, base change, distance to a line, comparisons of two operations.
