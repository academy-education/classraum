# Form QC — 2026-10-04

Every way a **delivered** test form can be wrong, checked on forms built by the
real assemblers against the live bank. Instrument:
`scripts/study-bank/form-qc.ts` (read only; `--selftest` first).

## How the forms were built

- The real `assembleFromBank` / `assembleActSection` /
  `assembleAdmissionSection` / `assembleToeflFromBank`, called exactly as the
  assemble and route endpoints call them, with `fetch` replaced by an
  in-memory PostgREST stand-in serving the live rows and a simulated exposure
  ledger. The stand-in throws on any other request, so nothing can be written.
- Loaded rows asserted equal to the live exact count per family (7,200 drawable
  rows). Unpaged reads are served **exactly the rows the live DB returns to the
  same unpaged query** (captured first), so the PostgREST 1000-row cap is
  reproduced, not approximated.
- One simulated student per section/variant, 6 consecutive forms, unseen-first
  (re-run at 8 forms; same findings): SAT R&W + Math x easy/hard route (M1 +
  routed M2), ACT x 4, SSAT and ISEE as full sittings on one ledger (so the
  two ISEE math blocks cannot share an item), TOEFL x 4 path/route combos
  (Reading M1+M2, Listening M1+M2, Writing, Speaking).
- Plus an exhaustion edge (ledger = 95% of the family seen long ago) and a
  bank-wide item sweep (the per-item checks over all 7,200 rows, so an item
  defect is listed whether or not a form happened to draw it).

**Self-test** (`--selftest`, 36 assertions): clean fixture forms pass every
check; 29 planted defects (one per mechanism: duplicate id, key not a choice, equal
choices, 3 choices, no explanation, SVG without viewBox / unparseable /
empty chart, "Question 4", letter in explanation, positional option, short
module, wrong clock, domain top-up, easy item on hard route, near-dup, shared
passage, shuffle broke key, numeric with no acceptable answers, item_type
mismatch, crash, two items from one bijective set, interleaved / reordered /
truncated / module-split passage, verbal type order, extra pilot, uncached
audio) each fire their check; and the REAL assembler run on a 1,200-row
fixture is reported truncated by `read_complete`.

**Denominators** (final run): 6,498 items checked across 198 forms; 3,840
listening + 264 speaking audio segments looked up in storage; 238 graphics
(50 bar, 74 table, 7 two-way, 105 SVG, 1 dot plot, 1 line); 5,886 explanations
scanned; 240 Build-a-Sentence, 48 Complete-the-Words, 168 Listen-and-Repeat,
96 Interview, 48 Writing tasks, 12 essays.

## What this instrument cannot see

Semantic leaks (an option set guessable without the source) — that is the
blind attack's job, not this one's. Near-duplicates are found only as
identical stem+passage+graphic or identical option set with a similar stem; a
paraphrased twin passes. Graphics and audio are checked against replicas of
the runner code (QuestionGraphicView could not be server-rendered — its
LanguageProvider hangs outside a browser); a change to either runner file
must be mirrored in form-qc.ts. One simulated student per variant: depth and
rotation effects across many students are toefl-form-depth.ts /
admission-form-depth.ts territory. Production row order for an unpaged read
is physical order; the snapshot reproduces it at capture time only.
