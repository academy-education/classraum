# Listening questions without the recording

Each item in your file is a question from an English listening test, with four options. The recording (a short
conversation or a lecture) is WITHHELD. Pick the option you think is most likely correct anyway, using anything in
the question and options. Answer every item.

Write a JSON object keyed by item id: {"1": {"pick": "A", "confident": true|false, "note": "under 10 words: your cue"}, ...}
Letters A-D only. Read only your blind file and this brief. Claude only, no database, no web.
